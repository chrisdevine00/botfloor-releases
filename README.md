# Botfloor releases

Downloads and automatic updates for Botfloor: a small robot on your Mac's desktop for each Claude Code session.

**[Download the latest version](https://github.com/chrisdevine00/botfloor-releases/releases/latest)**: get `Botfloor-<version>.dmg` from the release's Assets.

Requires macOS 14 or later, on Apple silicon or Intel. Installed copies update themselves from this repo's latest release (`appcast.xml`).

The source code isn't public.
